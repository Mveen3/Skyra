# Credits

## Project
- **Skyra** — 2D Jetpack Arena Shooter

## Design & Architecture
- **Concept & Gameplay Design:** Inspired by *Doodle Army 2: Mini Militia* (Appsomniacs LLC).
- **Technical Architecture & Specifications:** Authored by the Skyra core team (`docs/Skyra_Technical_Architecture.md`).
- **Implementation:** Pair programming between USER and Antigravity (Google DeepMind).

## Technology
- **Engine:** [Godot Engine](https://godotengine.org/) (v4.4.1 stable).
- **Language:** GDScript 2.0.
- **Physics & Navigation:** Custom 60 Hz deterministic AABB physics engine & NavGrid BFS pathfinder.
- **Audio:** SfxSynth procedural audio synthesizer (pure GDScript, 0 external audio libraries).
- **Art:** Vector Art DSL & CanvasItem procedural vector drawing.
